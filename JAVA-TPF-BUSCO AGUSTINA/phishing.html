¿Mensaje real o phishing?

El phishing busca que una persona entregue datos o ejecute una acción apresurada. La mejor defensa comienza por observar las señales antes de hacer clic.

⏱️

Urgencia

“Último aviso”, “ahora mismo” o amenazas de bloqueo intentan reducir el tiempo para pensar.

🔗

Enlaces extraños

Dominios inesperados, direcciones parecidas a las reales o enlaces acortados merecen revisión.

📎

Pedidos inusuales

Datos sensibles, transferencias, contraseñas o adjuntos inesperados son señales de alerta.
